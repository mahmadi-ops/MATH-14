    Section 5 Path Independence, Conservative Fields, and Potential Functions

    Before we begin discussing the actual topic of today’s lecture, we will need to study a particular type of a vector field known as a gradient field.
    🔗

    Subsection 5.1 Gradient Fields

    Definition 5.1. Gradient Field.

    The gradient field of a differentiable function \(f(x,y,z)\) is the field of gradient vectors
    🔗
    \begin{equation} \nabla f = \frac{\partial f}{\partial x}\mathbf i + \frac{\partial f}{\partial y}\mathbf j + \frac{\partial f}{\partial z}\mathbf k.\tag{5.1} \end{equation}
    🔗
    At each point \((x,y,z)\text{,}\) the gradient field gives a vector pointing in the direction of greatest increase of \(f\text{.}\) Let us emphasize that even though the function \(f\) is a scalar-valued function, its gradient is a vector-valued one by definition. As an example, see Figure 5.2.
    🔗
    In Figure 5.2, you see the scalar-valued function \(z = f(x,y) = x^2 + y^2\text{,}\) which is a function on \(\R^2\text{,}\) and according to the above definition, its gradient is
    🔗
    \begin{equation} \nabla f = \frac{\partial f}{\partial x}\mathbf i + \frac{\partial f}{\partial y}\mathbf j = 2x\,\mathbf i + 2y\,\mathbf j.\tag{5.2} \end{equation}
    The gradient field is visualized in the \(xy\)-plane and the value of the function \(f(x,y) = x^2 + y^2\) at each point \((x,y)\) is plotted on the \(z\)-axis. Intuitively, the gradient of a function \(f(x,y)\) at a point \((x_0,y_0)\) is a vector pointing in the direction of the steepest slope.
    🔗
    🔗

    Subsection 5.2 Path Independence and Some Basic Definitions

    In previous lectures, we saw that the line integral of a vector field depends on the path in general. Then, the natural question to ask is:
    🔗
    What are the conditions under which the line integral of a vector field \(\mathbf F\) from point \(A\) to point \(B\) is independent of the curve \(C\) taken to go from \(A\) to \(B\text{?}\)
    🔗
    🔗
    To answer this question, we will need some concepts and therefore we begin by explaining them.
    🔗

    Remark 5.3. Reminder.

    A smooth curve has no sharp corners or cusps; when the tangent vector turns, it does so continuously.
    🔗
    🔗

    Definition 5.4. Open, Connected, and Simply Connected Regions; Conservative Fields.

    • A region \(D\) is open if for every point \(P\) in \(D\) there is a disk with center \(P\) that lies entirely in \(D\text{,}\) which means that \(D\) doesn’t contain any of its boundary points.
      🔗
      🔗
    • Consider an open region \(D\) in space and a vector field \(\mathbf F\text{.}\) If the result of the line integral \(\int_C \mathbf F\cdot d\mathbf r\) from \(A\) to \(B\) is the same for all possible paths inside \(D\text{,}\) then the line integral \(\int_C \mathbf F\cdot d\mathbf r\) is said to be path-independent inside \(D\) and the field \(\mathbf F\) is said to be conservative on \(D\text{.}\)
      🔗
      🔗
    • If a vector field \(\mathbf F\) can be written as \(\mathbf F = \nabla f\text{,}\) where \(f\) is a scalar-valued function, then \(f\) is a potential function.
      🔗
      🔗
    • Piecewise smooth curves are curves that are made up of finitely many smooth pieces.
      🔗
      🔗
    • An open region \(D\) is said to be connected if any two points in \(D\) can be joined by a smooth curve that lies in the region.
      🔗
      🔗
    • \(D\) is simply connected, which means that every loop in \(D\) can be contracted to a point in \(D\) without ever leaving \(D\text{.}\) (See Figure 5.5.)
      🔗
      🔗
    🔗
    🔗
    🔗

    Subsection 5.3 Line Integrals in Conservative Fields

    Next, we will study the line integrals of conservative fields. As you will recognize, if you think of the gradient of a vector field as its derivative, then the fundamental theorem of line integrals makes a similar statement for vector-valued functions as the one made for definite integrals of scalar-valued functions, i.e., the one that you learned in MATH 12 and you know as FTC II.
    🔗

    Theorem 5.6. Fundamental Theorem of Line Integrals.

    Let \(C\) be a smooth curve joining the point \(A\) to the point \(B\) in the plane or in space and parametrized by \(\mathbf r(t)\text{.}\) Let \(f\) be a differentiable function with a continuous gradient vector \(\mathbf F = \nabla f\) on a domain \(D\) containing \(C\text{.}\) Then
    🔗
    \begin{equation} \int_C \mathbf F\cdot d\mathbf r = f(B) - f(A).\tag{5.3} \end{equation}
    🔗

    Proof.

    Assuming that the curve \(C\) is parametrised as \(\mathbf r(t) = x(t)\mathbf i + y(t)\mathbf j + z(t)\mathbf k\text{,}\) we have \(\mathbf v(t) = \dfrac{d\mathbf r}{dt} = \dfrac{dx}{dt}\mathbf i + \dfrac{dy}{dt}\mathbf j + \dfrac{dz}{dt}\mathbf k\) and we can rewrite the line integral as
    🔗
    \begin{align*} \int_C \mathbf F(x(t),y(t),z(t))\cdot d\mathbf r \amp= \int_a^b \nabla f\cdot\frac{d\mathbf r}{dt}\,dt\\ \amp= \int_a^b \left(\frac{\partial f}{\partial x}\mathbf i + \frac{\partial f}{\partial y}\mathbf j + \frac{\partial f}{\partial z}\mathbf k\right)\cdot \left(\frac{dx}{dt}\mathbf i + \frac{dy}{dt}\mathbf j + \frac{dz}{dt}\mathbf k\right)dt\\ \amp= \int_a^b \left(\frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} + \frac{\partial f}{\partial z}\frac{dz}{dt}\right)dt\\ \amp= \int_a^b \frac{df}{dt}\,dt = \int_a^b df = f(b) - f(a). \end{align*}
    🔗
    In Figure 5.7, the boundary of the region \(D\) is marked as dotted and the curve \(C\) is in red. According to the fundamental theorem, the line integral of a conservative vector field \(\mathbf F\) can be easily calculated by calculating the values of its corresponding potential function \(f\) at the beginning (point \(A\)) and end (point \(B\)) of the curve \(C\text{.}\)
    🔗
    The central idea of the theorem—that only the endpoints matter—is animated in Figure 5.8.
    🔗
    In the next example, we will see how we can use the above theorem.
    🔗

    Example 5.9. Example I.

    Consider the scalar-valued function \(f(x,y,z) = \dfrac{1}{\sqrt{x^2 + y^2 + z^2}}\text{.}\)
    🔗
    1. Calculate the gradient vector field \(\mathbf F(x,y,z) = \nabla f\text{.}\)
      🔗
      🔗
    2. Evaluate the line integral of the vector field \(\mathbf F(x,y,z) = \nabla f\) over the curve \(C_1\) parametrized as \(\mathbf r(t) = \cos(t)\mathbf i + \sin(t)\mathbf j + t\mathbf k\) from \((1,0,0)\) to \((1,0,2\pi)\text{.}\)
      🔗
      🔗
    3. What is the result of \(\int_{C_2} \mathbf F\cdot d\mathbf r\) from \((1,0,0)\) to \((1,0,2\pi)\) where \(C_2\) is the line connecting the two points?
      🔗
      🔗
    🔗
    🔗
    Solution.
    A. We compute the three partial derivatives of \(f(x,y,z) = \left(x^2+y^2+z^2\right)^{-1/2}\text{:}\)
    🔗
    \begin{align*} \mathbf F(x,y,z) = \nabla f \amp= \frac{\partial f}{\partial x}\mathbf i + \frac{\partial f}{\partial y}\mathbf j + \frac{\partial f}{\partial z}\mathbf k\\ \amp= -\left(\frac{x}{\left(x^2+y^2+z^2\right)^{3/2}}\right)\mathbf i - \left(\frac{y}{\left(x^2+y^2+z^2\right)^{3/2}}\right)\mathbf j - \left(\frac{z}{\left(x^2+y^2+z^2\right)^{3/2}}\right)\mathbf k. \end{align*}
    B. Of course, one way would be to calculate the line integral using the vector field calculated in part A (as we used to do); however, Theorem 5.6 provides us with a much more efficient way of calculating the line integral as follows:
    🔗
    \begin{equation} \int_{C_1} \mathbf F(x(t),y(t),z(t))\cdot d\mathbf r = f(1,0,2\pi) - f(1,0,0) = \frac{1}{\sqrt{1 + 4\pi^2}} - 1.\tag{5.4} \end{equation}
    C. The result is the same as part B, since the vector field \(\mathbf F(x,y,z) = \nabla f\) is a conservative field, which means that the result of the line integral is independent of the chosen path. Note that the line integral is calculated from \((1,0,0)\) to \((1,0,2\pi)\) in both cases. The two curves \(C_1\) and \(C_2\) are shown in Figure 5.10.
    🔗
    🔗
    🔗

    Subsection 5.4 Finding a Potential Function

    Example 5.11. Example II.

    Consider the vector field \(\mathbf F = yz\,\mathbf i + xz\,\mathbf j + (xy + 2z)\mathbf k\text{.}\)
    🔗
    1. Find a function \(f\) such that \(\mathbf F = \nabla f\text{.}\)
      🔗
      🔗
    2. Use the solution of part (A) to calculate the line integral from \((1,0,-2)\) to \((4,6,3)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Solution.
    A. Writing \(\mathbf F = yz\,\mathbf i + xz\,\mathbf j + (xy+2z)\mathbf k = \left\langle \dfrac{\partial f}{\partial x},\, \dfrac{\partial f}{\partial y},\, \dfrac{\partial f}{\partial z} \right\rangle\text{,}\) we match the components one at a time; the three steps are summarized in Figure 5.12.
    🔗
    Step I. Since \(\dfrac{\partial f}{\partial x} = yz\text{,}\) we integrate with respect to \(x\) (here \(x\) is the variable and \(y\) and \(z\) are constants), so
    🔗
    \begin{equation} f(x,y,z) = xyz + g(y,z),\tag{5.5} \end{equation}
    where the constant of integration \(g(y,z)\) is allowed to depend on \(y\) and \(z\text{.}\)
    🔗
    Step II. Since \(\dfrac{\partial f}{\partial y} = xz\text{,}\) we differentiate (5.5) with respect to \(y\text{:}\)
    🔗
    \begin{gather*} \frac{\partial}{\partial y}\Big(xyz + g(y,z)\Big) = xz + \frac{\partial g}{\partial y} = xz \quad\Rightarrow\quad \frac{\partial g}{\partial y} = 0, \end{gather*}
    so \(g\) does not depend on \(y\text{,}\) and we can write \(g(y,z) = h(z)\text{;}\) that is,
    🔗
    \begin{equation} f(x,y,z) = xyz + h(z).\tag{5.6} \end{equation}
    Step III. Since \(\dfrac{\partial f}{\partial z} = xy + 2z\text{,}\) we differentiate (5.6) with respect to \(z\text{:}\)
    🔗
    \begin{gather*} \frac{\partial}{\partial z}\Big(xyz + h(z)\Big) = xy + \frac{dh}{dz} = xy + 2z \quad\Rightarrow\quad \frac{dh}{dz} = 2z \quad\Rightarrow\quad h(z) = z^2 + C. \end{gather*}
    Putting the three steps together, we conclude
    🔗
    \begin{equation} f(x,y,z) = xyz + z^2 + C.\tag{5.7} \end{equation}
    B. By Theorem 5.6, with \(A(1,0,-2)\) and \(B(4,6,3)\text{,}\)
    🔗
    \begin{align*} \int_C \mathbf F\cdot d\mathbf r \amp= f(4,6,3) - f(1,0,-2)\\ \amp= \big((4)(6)(3) + 3^2\big) - \big((1)(0)(-2) + (-2)^2\big) = 81 - 4 = 77. \end{align*}
    🔗
    🔗

    Subsection 5.5 Conservative Fields are Gradient Fields

    Theorem 5.13. Conservative Fields are Gradient Fields.

    Let \(\mathbf F = M\mathbf i + N\mathbf j + P\mathbf k\) be a vector field whose components are continuous throughout an open connected region \(D\) in space. Then \(\mathbf F\) is conservative if and only if \(\mathbf F\) is a gradient field \(\nabla f\) for a differentiable function \(f\text{.}\)
    🔗
    🔗
    The content of Theorem 5.13, combined with Theorem 5.6 and the definition of path independence, can be organized into the following square of equivalent statements:
    🔗
    \begin{align*} \text{there exists a potential } f \text{ with } \mathbf F = \nabla f \quad\amp\Longleftrightarrow\quad \mathbf F \text{ is a conservative field}\\ \Big\Updownarrow\qquad\qquad\qquad \amp \qquad\qquad\qquad\Big\Updownarrow\\ \text{for any path } C:\ \int_C \mathbf F\cdot d\mathbf r = f(B) - f(A) \quad\amp\Longleftrightarrow\quad \int_C \mathbf F\cdot d\mathbf r \text{ is path-independent} \end{align*}
    Path independence means that all of the paths in Figure 5.14 give the same value of the line integral: if \(\mathbf F\) is conservative, then
    🔗
    \begin{equation} \int_{C_1} \mathbf F\cdot d\mathbf r = \int_{C_2} \mathbf F\cdot d\mathbf r = \int_{C_3} \mathbf F\cdot d\mathbf r = f(B) - f(A).\tag{5.8} \end{equation}
    🔗

    Subsection 5.6 The Loop Property of Conservative Fields

    Theorem 5.15. Loop Property of Conservative Fields.

    The following statements are equivalent.
    🔗
    1. \(\oint_C \mathbf F\cdot d\mathbf r = 0\) around every loop (that is, closed curve \(C\)) in \(D\text{.}\)
      🔗
      🔗
    2. The field \(\mathbf F\) is conservative on \(D\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Proof.

    We prove that (2) implies (1); the reverse direction runs the same computation backwards. We assume that \(\mathbf F\) is conservative. Then, as shown in Figure 5.16, we can think about any loop as \(C = C_1 \cup C_2\text{,}\) where \(C_1\) goes from \(A\) to \(B\) and \(C_2\) returns from \(B\) to \(A\text{.}\) Reversing the orientation of \(C_2\) produces the curve \(-C_2\text{,}\) and \(C_1\) and \(-C_2\) both connect \(A\) to \(B\text{.}\) Since \(\mathbf F\) is conservative, path independence gives \(\int_{C_1} \mathbf F\cdot d\mathbf r = \int_{-C_2} \mathbf F\cdot d\mathbf r\text{,}\) and therefore
    🔗
    \begin{align*} \oint_C \mathbf F\cdot d\mathbf r \amp= \int_{C_1} \mathbf F\cdot d\mathbf r + \int_{C_2} \mathbf F\cdot d\mathbf r\\ \amp= \int_{-C_2} \mathbf F\cdot d\mathbf r + \int_{C_2} \mathbf F\cdot d\mathbf r\\ \amp= -\int_{C_2} \mathbf F\cdot d\mathbf r + \int_{C_2} \mathbf F\cdot d\mathbf r\\ \amp= 0. \end{align*}
    Hence \(\oint_C \mathbf F\cdot d\mathbf r = 0\) for any loop \(C\text{.}\)
