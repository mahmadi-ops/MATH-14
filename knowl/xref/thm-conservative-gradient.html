Theorem 5.13. Conservative Fields are Gradient Fields.

Let \(\mathbf F = M\mathbf i + N\mathbf j + P\mathbf k\) be a vector field whose components are continuous throughout an open connected region \(D\) in space. Then \(\mathbf F\) is conservative if and only if \(\mathbf F\) is a gradient field \(\nabla f\) for a differentiable function \(f\text{.}\)
