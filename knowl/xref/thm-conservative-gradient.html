Theorem 1.5.14. Conservative Fields are Gradient Fields.

Let \(\mathbf F = M\mathbf i + N\mathbf j + P\mathbf k\) be a vector field whose components are continuous throughout an open connected region \(D\) in space (Definition 1.5.4). Then \(\mathbf F\) is conservative if and only if \(\mathbf F\) is a gradient field \(\nabla f\) for a differentiable function \(f\text{.}\)
🔗
🔗

Proof.

First, we prove that a gradient field is conservative; we assume that \(\mathbf F = \nabla f\) for a differentiable function \(f\text{.}\) If \(C\) is any piecewise smooth curve in \(D\) running from \(A\) to \(B\text{,}\) then Theorem 1.5.6 gives
🔗
\begin{equation*} \int_C \mathbf F\cdot d\mathbf r = f(B) - f(A), \end{equation*}
which depends only on the endpoints \(A\) and \(B\text{,}\) and not on the curve \(C\) joining them. The line integral is therefore path-independent in \(D\text{,}\) which is to say that \(\mathbf F\) is conservative on \(D\) (Definition 1.5.4).
🔗
Next, we prove that a conservative field is a gradient field; we assume that \(\mathbf F\) is conservative on \(D\text{,}\) and we build a potential function for it. Fix a point \(A_0\) of \(D\text{.}\) Because \(D\) is connected, every point \((x,y,z)\) of \(D\) can be joined to \(A_0\) by a curve lying in \(D\text{;}\) and because \(\mathbf F\) is conservative, the value of the line integral along such a curve does not depend on which one we choose. We may therefore define
🔗
\begin{equation} f(x,y,z) = \int_{A_0}^{(x,y,z)} \mathbf F\cdot d\mathbf r ,\tag{1.5.10} \end{equation}
the integral being taken along any curve in \(D\) from \(A_0\) to \((x,y,z)\text{.}\) It remains to check that \(\nabla f = \mathbf F\text{.}\)
🔗
Fix a point \((x,y,z)\) of \(D\text{.}\) Since \(D\) is open, there is a \(\delta > 0\) such that every point within distance \(\delta\) of \((x,y,z)\) also lies in \(D\text{.}\) For \(0 < |h| < \delta\text{,}\) let \(L_h\) be the straight segment from \((x,y,z)\) to \((x+h,y,z)\text{,}\) which then lies in \(D\text{.}\) Following a curve from \(A_0\) to \((x,y,z)\) and then travelling along \(L_h\) produces a curve in \(D\) from \(A_0\) to \((x+h,y,z)\text{,}\) so (1.5.10) gives
🔗
\begin{equation*} f(x+h,y,z) - f(x,y,z) = \int_{L_h} \mathbf F\cdot d\mathbf r . \end{equation*}
Parametrizing \(L_h\) by \(\mathbf r(t) = (x+t)\mathbf i + y\mathbf j + z\mathbf k\) with \(0 \le t \le h\) gives \(d\mathbf r = \mathbf i\,dt\text{,}\) so that \(\mathbf F\cdot d\mathbf r = M(x+t,y,z)\,dt\) and
🔗
\begin{equation*} \frac{f(x+h,y,z) - f(x,y,z)}{h} = \frac{1}{h}\int_0^h M(x+t,y,z)\,dt . \end{equation*}
The right-hand side is the average value of \(M\) along the segment from \((x,y,z)\) to \((x+h,y,z)\text{.}\) As \(h \to 0\) that segment shrinks down to the single point \((x,y,z)\text{,}\) and since \(M\) is continuous its values on the segment all approach \(M(x,y,z)\text{;}\) so their average does too. Therefore \(\dfrac{\partial f}{\partial x} = M\text{.}\) Repeating the argument with segments in the \(\mathbf j\) and \(\mathbf k\) directions gives \(\dfrac{\partial f}{\partial y} = N\) and \(\dfrac{\partial f}{\partial z} = P\text{.}\) Hence
🔗
\begin{equation*} \nabla f = M\mathbf i + N\mathbf j + P\mathbf k = \mathbf F , \end{equation*}
and \(f\) is differentiable because its partial derivatives \(M\text{,}\) \(N\text{,}\) and \(P\) are continuous on \(D\text{.}\) So \(\mathbf F\) is the gradient field of \(f\text{.}\)
